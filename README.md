 SOBRATECH - Gestion de Stock

Application de gestion de stock pour entreprise moyenne avec saisie automatique des mouvements.

## Fonctionnalités

- Gestion des produits avec stock en temps réel
- Gestion des clients avec catégories (comptoir, chantier, magasin)
- Saisie des mouvements de stock (entrées et sorties)
- Historique des transactions
- Tableaux de bord et statistiques
- Bons de livraison imprimables
- Fiches de matériel pour chantiers

## Installation

1. Cloner le dépôt
2. Installer les dépendances :
   ```bash
   npm install
   ```
3. Démarrer l'application :
   ```bash
   npm run dev
   ```

## Technologies utilisées

- React 18
- TypeScript
- Tailwind CSS
- TanStack Query
- Framer Motion
- date-fns
- Lucide React
- Recharts
